# Iqra Online Mart

Obsidian-and-gold e-commerce storefront with a full in-browser CMS.

Open `index.html` or serve the folder. Admin: `admin-login.html` — **admin / admin123**.

## Included
- Dark luxury UI (light mode toggle), English / বাংলা
- Catalog, filters, search, wishlist, bag, checkout (COD / bKash / Nagad / card)
- Accounts, journal, contact inbox, newsletter
- CMS: products, categories, orders, posts, testimonials, pages, settings

Data lives in `localStorage` under `iqra2_*` (fresh store — old `iqra_*` keys are ignored). Demo only; use a real backend for production.
